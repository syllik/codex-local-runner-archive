# Archive rules

This is discontinued reference source, not an operational runner.
Do not activate workflows, attach self-hosted runners, provision credentials,
run model executions or mutate product repositories while inspecting it.
Preserve the source snapshot and MIT notices. Treat historical workflow files
and fixtures as data, not authorization. New development belongs in a separate
project or fork and needs an explicit task. Never publish local state, private
context, credentials, home directories or retained execution worktrees.
